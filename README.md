# TF-IDF 실험실

짧은 문장을 입력하고 전처리부터 TF-IDF까지 살펴보는 교육용 웹 앱입니다. 한 입력칸을 한 문서로 취급합니다.

## 실행

Python 3.9 이상에서 실행합니다.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

브라우저에서 http://localhost:5050 을 엽니다. 로컬 학습용 Flask 서버입니다.

## 전처리

- 한국어: [Kiwi](https://github.com/bab2min/kiwipiepy)의 기본 사전과 모델을 설치 시 내려받습니다. 첫 분석 때 모델을 로딩합니다. 사용자 사전은 단어를 한 줄에 하나씩 입력하며 NNP(고유명사), 가중치 5로 추가합니다. 기본 사전과 사용자 사전은 분석기가 사용하는 자료이며 화면에 전체 사전을 나열하지는 않습니다.
- 일반 모드: 정규식으로 단어와 문장부호를 분리하고 [NLTK PorterStemmer](https://www.nltk.org/api/nltk.stem.PorterStemmer.html)로 영어 어간을 추출합니다. 추가 NLTK 데이터 다운로드는 필요 없습니다. 다른 언어의 형태소 분석이나 stemming은 지원하지 않습니다.
- 소문자 변환, 필터, 불용어 제거는 독립적으로 설정합니다. 한국어는 명사, 동사, 형용사, 일반부사, 외국어, 숫자, 어근을 남깁니다. 불용어 제거는 기본으로 켜져 있습니다. 언어별 학습용 기본 목록을 제공하며, 목록을 직접 편집하거나 기본값으로 복원할 수 있습니다. 언어별 목록과 불용어 제거 옵션을 localStorage에 즉시 자동 저장해 새로고침·브라우저 재시작 후에도 복원합니다. 비워 둔 목록과 기본 목록 복원 결과도 유지합니다. 같은 브라우저와 접속 주소에서 유지되며, 서버나 다른 기기에 공유하지 않습니다. 브라우저 사이트 데이터를 삭제하면 초기화됩니다. 저장이 불가능하면 화면에 안내하고 현재 세션에서 계속 사용할 수 있습니다. 보편적인 정답 목록은 아니므로 문서의 목적에 맞게 조정하세요.
- 불용어는 소문자 변환 다음, 영어 stemming 이전의 토큰과 대소문자 구분 없이 정확히 비교합니다. 한국어는 형태소 단위입니다. 제거된 토큰, 이유, 제거 개수를 별도 열에 표시하며 단어 횟수와 문서 길이 계산에서도 제외합니다. 목록은 최대 300개 토큰이며, 비우면 불용어를 제거하지 않습니다.
- 한국어 어간은 형태소 분석 결과로 보여주며 영어 stemming과 구분합니다. 원문 형태는 토큰 셀에 마우스를 올려 확인할 수 있습니다.
- 입력과 옵션 변경 후 자동으로 재분석합니다. 언어별 문장 초안을 유지합니다. 문장과 사용자 사전은 새로고침 후 초기화되며 별도 저장하지 않습니다.

## 계산

`TF = 단어 출현 횟수 (원시 빈도)`

`DF = 해당 단어가 등장한 문서 수`

`IDF = ln(N / DF)`

`TF-IDF = TF × IDF`

평활화와 벡터 정규화는 사용하지 않습니다. 모든 문서에 등장한 단어의 점수는 0입니다. 문서가 하나라면 모든 점수가 0이므로 비교할 문장을 추가하세요. 비어 있는 입력칸은 제외하고, 전처리 후 토큰이 없는 문서는 유지하며 TF를 0으로 처리합니다. 최대 10개 문장, 문장당 500자, 사용자 사전 30개 단어를 지원합니다.

## BM25 검색 모델 비교

검색어를 입력하면 같은 전처리와 불용어 목록을 적용한 뒤 TF-IDF, BM25, BM25L, BM25+의 문장별 점수·순위를 비교합니다. 검색어는 코퍼스 통계에 포함하지 않으며, 검색 토큰의 반복은 중복 제거합니다. 각 모델의 점수는 단어별 기여도의 합입니다. TF-IDF 검색 점수는 기존 문서 TF-IDF 가중치 중 검색어에 해당하는 값의 합이며 코사인 유사도는 아닙니다.

문장 선택 버튼으로 단어별 IDF, 빈도 가중치, 기여도와 문서 길이 보정을 확인할 수 있습니다. `k1`은 빈도 포화, `b`는 길이 보정, `delta_l`과 `delta_plus`는 각 변종의 하한 보정을 조절합니다. 반복·길이 비교 예제 버튼은 문장과 검색어를 교체하며 불용어 목록은 유지합니다. 점수·순위 변화량은 직전 분석 결과의 같은 번호 문장 대비입니다. 모델마다 점수 척도가 다르므로 절대 점수로 모델의 우열을 판단하지 않습니다. 동점은 같은 순위를 표시합니다(예: 1, 1, 3).

공식은 [BM25 변종 재현성 연구의 Table 1](https://cs.uwaterloo.ca/~jimmylin/publications/Kamphuis_etal_ECIR2020.pdf)을 참고했습니다. 모든 로그는 자연로그입니다. `f`는 원시 단어 횟수, `L`은 전처리 후 토큰 수, `avgL`은 문서 평균 토큰 수입니다.

```text
A = 1 - b + b * L / avgL
c = f / A
TF-IDF = Σ f * ln(N / DF)
BM25 = Σ ln(1 + (N - DF + 0.5) / (DF + 0.5)) * (k1 + 1) * f / (f + k1 * A)
BM25L = Σ ln((N + 1) / (DF + 0.5)) * (k1 + 1) * (c + delta_l) / (k1 + c + delta_l)
BM25+ = Σ ln((N + 1) / DF) * [(k1 + 1) * f / (f + k1 * A) + delta_plus]
```

BM25는 양수 IDF와 `(k1+1)` 배율을 사용하고 실제 길이를 쓰므로 Lucene 구현과 정확히 같은 점수를 보장하지 않습니다. BM25L/+는 각각의 IDF를 사용합니다. 불일치 단어(`f=0`)와 코퍼스에 없는 단어(`DF=0`)는 모든 모델에서 0으로 처리하며, BM25L/+ 하한 보정도 일치하는 단어에만 적용합니다. 전체 문서 토큰 수가 0이면 모든 점수는 0입니다. `delta=0`이어도 모델별 IDF가 달라 점수가 같지는 않습니다. 검색어·파라미터는 새로고침 후 기본값으로 돌아갑니다.
