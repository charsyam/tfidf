04

단어의 중요도

TF = 단어 출현 횟수 (원시 빈도)
IDF = ln(문장 수 / 단어가 등장한 문장 수)
TF-IDF = TF × IDF

모든 문장에 등장하면 IDF는 0입니다. 평활화와 벡터 정규화는 적용하지 않습니다.

선택 문장의 단어 점수

06

검색 모델 비교

모델별 점수 크기는 척도가 다릅니다. 순위와 같은 모델의 변화량을 비교하세요. 괄호 안 변화량은 직전 분석 대비이며 동점은 같은 순위입니다.

선택 문장 · 검색 단어별 기여도

모델별 공식과 차이
f = 단어 횟수, L = 문서 토큰 수, avgL = 평균 토큰 수
A = 1 − b + b × L / avgL, c = f / A
TF-IDF: Σ f × ln(N/DF)
BM25: Σ ln(1 + (N − DF + 0.5)/(DF + 0.5)) × (k₁ + 1)f/(f + k₁A)
BM25L: Σ ln((N + 1)/(DF + 0.5)) × (k₁ + 1)(c + δ)/(k₁ + c + δ)
BM25+: Σ ln((N + 1)/DF) × [(k₁ + 1)f/(f + k₁A) + δ]

합계는 중복을 제거한 검색 토큰에 대해 계산합니다. f=0 또는 DF=0이면 기여도는 0입니다. TF-IDF는 검색 단어의 기존 가중치 합이며 코사인 유사도가 아닙니다. BM25는 양수 IDF를 쓰고 (k₁+1) 배율을 포함합니다. BM25L/+는 각각 고유 IDF를 사용합니다. δ=0이어도 IDF가 달라 모델 점수가 같지는 않습니다.
